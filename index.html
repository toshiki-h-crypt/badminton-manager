説明

以前に同じペアだった回数に応じて減点します。値を上げると同じペアを避けやすくなり、下げると再登場しやすくなります。例：同じペアが過去3回なら、係数500で合計1500点の減点です。0にすると減点効果がなくなります。

説明

過去に対戦した相手との重複を減点します。値を上げると、対戦相手の組み合わせがより分散します。0にすると減点効果がなくなります。

説明

全参加者の平均より出場回数が少ない選手を候補に含めると加点します。値を上げると、出場が少ない選手を優先しやすくなります。

説明

連続出場回数に応じて減点します。値を上げると連続で出ている選手が休みやすくなり、下げると連続出場を許容しやすくなります。0にすると減点効果がなくなります。

説明

レベル設定のオプションが「レベル均等」または「レベル統一」の場合にだけ有効です。「レベル均等」はペア内のレベル差が1以内なら加点します。「レベル統一」は両チームのレベル合計が近いほど加点し、大きく離れると減点します。係数を上げると、選んだ基準を強く反映します。

説明

オプションが「ミックス優先」の場合だけ有効です。男女が分かる選手同士のペアを加点し、両チームがミックスなら追加加点します。係数を上げるほどミックス編成を優先します。

説明

前回と異なるコートになった選手を加点します。値を上げるとコート移動を促し、下げると前回と同じコートになりやすくなります。

説明

選択可能な選手内で、最多と最少の出場回数の差がこの値以上なら、最少出場の選手を優先候補にします。値を下げると早い段階から均等化し、上げると大きな差ができるまで優先しません。点数係数ではなく、選手選定のしきい値です。

説明

組み合わせ候補を生成・採点する回数です。増やすと良い候補を見つける可能性が上がりますが、生成に時間がかかります。上位10候補から選ぶ仕組みなので、増加による改善幅は一定ではありません。
